## Name

**Cue.** Lowercase `cue` only where the lens draws it. Never "Earshot".

## Colour

| role | value | use |
|---|---|---|
| background | #d3dbe8 → #eef1f5, 135° | every slide and the phone UI; never a flat fill |
| bloom | #fff3d6 at 90%, heavy blur | one warm ellipse, top right |
| ink | #000000 | all primary text |
| muted | #4a5262 | captions, kickers, notes |
| accent | #f2b64c | once per slide, a short rule above the headline |
| hairline | #c5cdd9 | rules and borders |
| lens | #1a1d1a | the only dark surface |
| HUD | #5ee07a | text inside a lens card only; dim state #2f5a3a |

Green and monospace appear only inside a lens card.

## Type

- Newsreader Medium: the name and headlines.
- Public Sans Regular: body, captions, kickers (uppercase, +14% tracking).
- IBM Plex Mono: only text that is literally on the lens, and technical labels.
- Nothing under 18 px on a 1920×1080 slide.
